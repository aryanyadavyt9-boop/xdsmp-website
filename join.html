How to join xDSMP

Pick your edition and follow the steps.

Java Edition

  1. Open Minecraft Java Edition at version 1.21.11 (matching ).
  2. Select Multiplayer, then Add Server.
  3. Enter any name, and paste the address into Server Address.
  4. Select Done, then double-click xDSMP.
Address

Bedrock Edition

  1. Open Minecraft Bedrock Edition.
  2. Go to Play, then Servers, then Add Server.
  3. Enter any name and this host as the address.
  4. Enter the port shown below, save, and join.
